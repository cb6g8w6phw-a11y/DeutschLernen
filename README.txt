DeutschLernen – aplikacja do nauki niemieckiego (SwiftUI, iOS 16+)

1. Mac z Xcode + XcodeGen:  brew install xcodegen
2. ./build_ipa.sh  -> powstaje DeutschLernen.ipa (niepodpisany)
3. Zainstaluj przez SideStore/AltStore (podpisze go twoim Apple ID).
4. W aplikacji: Ustawienia -> wklej darmowy klucz z aistudio.google.com/apikey
